# IT Security Support Lab

## About This Project

I made this project to practice basic IT support and security tasks using Ubuntu Linux.

I used a virtual machine to create different situations that someone working in IT might deal with. I practiced fixing problems, checking security settings, and using Linux commands.

I also wrote down what I did for each task and recorded my work in the terminal.

## Tools I Used

- Ubuntu Linux
- Oracle VirtualBox
- Linux Terminal
- Git and GitHub
- Asciinema

## What I Did

### Ticket 001: Creating a User Account

I created a user account for a pretend employee named Amy.

I checked her account information and made sure she didn't have administrator permissions.

### Ticket 002: Managing File Access

I created a folder that Amy wasn't allowed to open.

I tested her access and confirmed that it was blocked. Then I added her to a group that had permission to use the folder.

I tested it again to make sure she could access it.

### Ticket 003: Checking Failed Logins

I tested what happens when someone enters the wrong password while trying to log in.

I looked through Ubuntu's logs to find the failed login attempt and checked Amy's account status.

### Ticket 004: Firewall and System Updates

I checked the firewall on my Ubuntu system and found that it wasn't turned on.

I turned it on, set it to block incoming connections by default, and installed available updates.

After restarting Ubuntu, I checked that the firewall was still working.
